# AdSwitch

Маленька програма для Windows: коли в десктопному **Spotify** починається реклама, вона приглушує Spotify і вмикає твій плейліст зі **SoundCloud**. Реклама закінчилась — музика плавно повертається до Spotify.

> **Неофіційний проєкт.** AdSwitch не пов'язаний зі Spotify AB, SoundCloud чи їхніми власниками. Усі назви належать їхнім правовласникам.

## Що вміє

- Розпізнає рекламу в Spotify за автором і назвою, які віддає Windows (працює з безкоштовним акаунтом, API Spotify не потрібен).
- Приглушує лише звук програми Spotify, інші програми не чіпає.
- Грає публічний плейліст SoundCloud, поки триває реклама.
- Два режими повернення до Spotify: плавний перехід або «доіграти пісню SoundCloud, а потім увімкнути Spotify».
- Працює в треї, може запускатися разом з Windows.
- Сам докачує `yt-dlp` і `mpv`, які потрібні для SoundCloud.

## Встановлення

1. Завантаж `AdSwitch-Setup.exe` з розділу [Releases](../../releases).
2. Запусти інсталятор.
   - Windows може показати синє вікно «Windows захистила ваш ПК», бо інсталятор не підписаний сертифікатом. Натисни **Докладніше → Все одно запустити**. Код програми відкритий, його можна перевірити або зібрати самому (див. нижче).
3. Відкрий AdSwitch і встав посилання на свій плейліст SoundCloud.
4. Натисни **Запустити**. При першому запуску програма завантажить `yt-dlp` і встановить `mpv` через `winget`, для цього потрібен інтернет.
5. Запусти Spotify і вмикай музику.

## Вимоги

- Windows 10 або 11 з `winget` (Диспетчер пакетів Windows).
- **Десктопний** Spotify. Веб-версія, телефон і планшет не підтримуються.
- **Публічний** плейліст SoundCloud (у режимі інкогніто він має відкриватись без входу).

## Як це працює

Windows знає, що зараз грає в Spotify (так само, як для кнопок керування на клавіатурі). Реклама Spotify зазвичай підписана автором `Spotify` або назвою на кшталт `Advertisement`. Коли програма це бачить, вона вимикає звук процесу `Spotify.exe` і запускає `mpv`, який через `yt-dlp` відтворює твій плейліст SoundCloud. Після реклами все повертається назад.

## Якщо реклама не розпізнається

Spotify може підписувати рекламу інакше залежно від країни чи мови. Відкрий вкладку **Журнал**: там видно, що саме Windows повідомляє про Spotify. Потім на вкладці **Додатково** додай потрібні слова в поля «Автор реклами» або «Назва реклами» (через кому).

## Відомі обмеження

- Формат підпису реклами Spotify може змінитися без попередження.
- SoundCloud час від часу змінює свій сайт, через що `yt-dlp` потребує оновлення. Програма оновлює свою копію раз на добу, але інколи треба зачекати на новий випуск `yt-dlp`.
- Режим «Доіграти пісню» ставить Spotify на паузу через керування медіа Windows. Це може поводитись по-різному на різних збірках Windows.
- Програму не тестовано на всіх конфігураціях. Якщо щось не працює, створи [Issue](../../issues) і додай вміст вкладки «Журнал».

## Важливо знати

Програма приглушує рекламу Spotify й підміняє її іншою музикою. Умови користування Spotify обмежують обхід реклами, тому використання AdSwitch може суперечити цим умовам. Також SoundCloud не призначений для відтворення поза його власним плеєром. Ти користуєшся програмою на власний ризик і сам відповідаєш за дотримання правил сервісів. Автор не надає гарантій і не несе відповідальності за наслідки (зокрема за можливі обмеження акаунтів).

## Збірка з вихідного коду

Потрібен Python 3.12 для Windows (на новіших версіях пакет `winsdk` не збирається).

```
build.bat
```

Результат: `dist\AdSwitch.exe`. Щоб зробити інсталятор, відкрий `AdSwitch.iss` в [Inno Setup](https://jrsoftware.org/isinfo.php) і натисни Compile.

## Оновлення

Нова версія встановлюється поверх старої: просто запусти новий `AdSwitch-Setup.exe`. Налаштування зберігаються окремо в `%APPDATA%\AdSwitch`.

## Видалення

«Параметри → Програми → AdSwitch → Видалити». Щоб прибрати ще й налаштування та завантажений `yt-dlp`, видали теку `%APPDATA%\AdSwitch`.
